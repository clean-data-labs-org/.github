# Clean Data Labs

We build tools for public data, starting with SAM.gov federal contract opportunities.

**For small federal contractors:** tell us one SAM.gov search and a person checks each matching notice before it reaches you. Start with a [free hand-checked sample](https://clean-data-labs-org.github.io/?r=gh-org-profile): one search, the last 7 days, up to 10 notices.

**For developers:**
- [samgov-opportunities-mcp](https://github.com/clean-data-labs-org/samgov-opportunities-mcp): an open-source MCP server for searching SAM.gov opportunities from Claude, Cursor, and other MCP clients. Install it from [PyPI](https://pypi.org/project/samgov-opportunities-mcp/) with `uvx samgov-opportunities-mcp`.
- [SAM.gov opportunities actor](https://apify.com/cleandatalabs/samgov-opportunities) on the Apify Store.
